# Store listing draft

App name: Termux-Sathi

Short description:
Learn Linux commands in Hindi with offline lessons and a practice terminal.

Full description:
Termux-Sathi helps you understand Linux commands through Hindi and Hinglish explanations, offline lessons and hands-on file practice.

Explore 54 lessons covering terminal basics, files, networking concepts, Python, Git, security awareness and responsible lab practice. Use the Explain screen to understand a command's purpose and expected output. Test the basics with a five-question quiz and keep track of the lessons you have opened.

Practice creating folders, writing text files and reading them in the app's private directory. Network, package-manager, Git and system-identity examples are clearly labelled teaching simulations. The app does not perform real scans, install Linux packages or execute Python or arbitrary shell scripts.

No account or internet connection is needed. The app contains no ads or in-app purchases. Practice files and learning progress remain on your device, with an in-app option to delete them.

Termux-Sathi is an independent educational app. It is not the official Termux or Kali Linux application and is not affiliated with those projects.

Suggested category: Education
